## Заключение и выводы
1. Освоено развёртывание Redmine в виртуальной среде и работа с его веб-интерфейсом.
2. Изучено взаимодействие **Ruby**, **Apache2**, **Passenger** и **PostgreSQL**: запуск приложения, обработка запросов и хранение данных.
3. Настроены подключение к базе данных, права доступа к рабочим каталогам и административная учётная запись Redmine.
4. Установлена дополнительная тема оформления; подготовлен сценарий резервного копирования базы, вложений и конфигурации.
5. Изучены средства диагностики по журналам Apache2, Redmine и PostgreSQL, а также особенности установки современных версий ПО по методическим рекомендациям.
6. Изучены базовые операции Git: получение репозитория с GitHub, локальная настройка автора, подготовка файлов к фиксации и работа с историей изменений. Файлы и коммиты учебного проекта добавляются отдельно.

## Как запустить Redmine после включения компьютера

1. Запустить виртуальную машину **Ubuntu** в VirtualBox.
2. Проверить сервер базы данных и веб-сервер:

   ```bash
   pg_lsclusters
   systemctl is-active apache2
   ```

   Для PostgreSQL ожидается статус `online` у кластера `16/main`, для Apache2 — `active`.

3. Если службы не запущены, запустить их:

   ```bash
   sudo pg_ctlcluster 16 main start
   sudo systemctl start apache2
   ```

4. Открыть Redmine **в браузере Ubuntu**:

   ```text
   http://localhost/redmine/
   ```

5. Чтобы открыть Redmine **из Windows**, узнать IP-адрес Ubuntu:

   ```bash
   hostname -I
   ```

   При сетевом адаптере VirtualBox в режиме **«Сетевой мост»** открыть в браузере Windows:

   ```text
   http://<IP-адрес-Ubuntu>/redmine/
   ```

   Например, если IP Ubuntu — `192.168.1.105`, адрес будет `http://192.168.1.105/redmine/`. Фактический IP может меняться; виртуальная машина должна быть включена.
